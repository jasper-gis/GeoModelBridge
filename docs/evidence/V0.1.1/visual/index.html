PNG 方向对照 已确认

源图 U 箭头向右、V 箭头向上，TL / TR 在上，BL / BR 在下。修复后的两个 GDB 渲染均保持该方向；红青双影中的标签也未上下颠倒。源图四象限颜色仅作为参考，当前渲染不能证明颜色显示完全正确。

JPEG 方向对照 已确认

测试 JPEG 由同一方向图生成（RGB、质量 95、不做色度抽样），保留非对称标签和箭头。该步骤只用于制作测试输入，产品转换路径没有把 JPEG 改写为另一种图像格式。两个后端的结果均为 U 向右、V 向上，与源 JPEG 一致。

GDB 独立副本可显示已确认alpha 原库与独立复制库的导出 PNG 字节相同，当前不证明透明混合正确。
六面颜色、透明度、接缝完整图形验收尚未通过红青双影干扰；须在无立体模式下复核。结构回读测试与此图形结论分开记录。

其余固定视角

两个立方体均包含斜俯视、对侧斜仰视和顶视，便于复核全部面。混合材质、Alpha 和独立副本也保存了原始导出，当前不标记为完整图形验收通过。

重现与设置

本地场景 EPSG:32650；绝对高程 Shape.Z、米、偏移 0、夸张 1；没有底图和高程面；图层使用白色 Multiply 网格符号。14 个相机均显式为 LOCAL 三维相机，PNG 为 1280 × 960。试验 Isometric 未消除双影。工程中的 9 条 GDB 连接已核对为交付目录内的相对路径，完整解压目录后可保持路径关系。

需要最终复核时，在 ArcGIS Pro“项目 → 选项 → 显示 → 立体模式”确认无立体显示，再重新运行导出。当前不能可靠读取该 UI 设置，故未推断它的具体存储值，也未更改全局或管理员配置。
