# 验收与支持边界

以下三层验收彼此独立。自动测试通过不等于目标软件显示验收通过。

| 样本 | 自动数据验收 | 目标软件人工验收 |
|---|---|---|
| color-cube | 六材质、面片绑定和颜色读回 | 六面颜色分区，无串位 |
| uv-plane | UV 数值与贴图原始字节/解码像素 | U/V 箭头和四角方向不翻转、不镜像 |
| mixed-materials | 两纹理加一纯色，材质绑定 | 所有分区都正确显示 |
| alpha-plane | RGBA 含 0/128/255 Alpha 值 | 镂空、半透明区域正确，无黑/白底 |
| seam-cube | 24 角点、8 几何位置、6 法线方向 | UV 接缝与硬边符合预期 |
| 单独复制 GDB | 新进程仅读复制库并核对纹理 | 原模型和中间包不可访问时仍能显示 |

在 ArcGIS Pro 或 GeoScene Pro 中新建本地场景，添加 GDB 的 Models 要素类，使用一致的材质显示设置、光照和视角。记录软件完整版本、显卡/驱动、显示选项及结果。不要用不同渲染器的逐像素截图相同作为唯一判断条件。

视觉验收记录模板：

```text
软件版本：
GDB 成果路径：
源资源是否不可访问：
六色分区 / UV箭头 / 多材质 / 透明镂空 / 接缝硬边：通过 / 不通过
异常描述及所涉材质：
截图或录屏：
验收人及时间：
```

## 目标存储精度与纹理方向

- 目标 RGB 为 8 位；材质透明度为整数百分比。报告保留源 RGBA 和实际存储值，不宣称任意浮点材质无损。
- 所有有 UV 的 patch 按 `U=sourceU, V=1-sourceV` 映射后再进行单精度数值核对，无纹理材质采用相同 UV 语义；误差阈值为 `max(1,abs(value))*2e-6`，中间包仍保留源 UV。
- 本机 Pro 3.6.2 写入 GDB 后，法线每分量按 `floor(float32(n)*128+0.5)/128` 量化，不重新归一化。验证器先检查 builder 的单精度结果，再逐分量严格核对 GDB 编码预测值；不会仅放宽数值容差。报告保留源法线摘要及最大分量、角度、长度误差。中间包保留源值，GDB 法线不是逐位无损。该规则来自本机实测，不是 Esri 对其他版本的公开保证。
- FileGDB 几何受空间参考 XY/Z resolution 约束，报告记录验收容差。
- PNG 容器元信息（ICC、文本等）不进入 Multipatch；PNG 解码像素保留，JPEG 压缩文件字节保留。色彩管理的最终外观需人工验收。
- V0.1.0 未做上述目标 V 映射，本次图形调查发现方向参考图上下颠倒；旧版数值读回通过不能证明方向正确。V0.1.1 修复必须重新生成成果并用箭头、四角及非对称图案验收。

图形结果按具体目标软件版本记录。创建场景和导出图片的方法见 [显示工程说明](visual-acceptance-setup.md)，当前通过与未通过项见 [V0.1.1 验证记录](validation-v0.1.1.md)。开发环境、源码编译或 SDK 读回成功均不能替代图形结论。

只有满足支持范围、数据读回、独立交付及目标版本显示验收，才可对具体模型声明本项目定义的“常规颜色及贴图保留”。
