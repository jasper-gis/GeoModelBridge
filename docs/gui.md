# Windows 图形界面 · V0.1.10

入口为本机 `releases/V0.1.10/bin/geomodelbridgeGUI.exe`，默认源码安装位置为 `dist/bin`。GUI 自带 .NET，原生 FileGDB 写入端与官方运行库位于旁边的 `native-filegdb` 子目录；保留完整发布目录。客户机需 Windows x64 和 Visual C++ x64 运行库，无需安装 ArcGIS Pro。

1. 点击“检查运行环境”，核对 CLI 版本、原生写入端和 FileGDB 坐标系目录。
2. 选择源 FBX 和尚不存在的新 GDB 路径，需要时添加额外贴图目录。
3. 填写米制投影 WKID 与 X/Y/Z 原点；这些参数不执行配准或重投影。
4. 选择 GIS 静态兼容或严格检查策略。转换选项中默认勾选“缺少贴图时使用材质颜色继续转换”；如果要求完整图片，取消勾选。后端固定为原生 FileGDB，无需选择。
5. 点击转换，完成后查看中文摘要或原始 JSON。失败后可用“换个新名称”重试，保留已有报告与成果。

演示按钮显式加载自带带贴图模型与测试坐标；演示坐标不代表用户模型的实际位置。切换模型后需重新确认定位参数。

缺图回退保留原材质颜色与标量透明度，有效图片仍正常转换；报告列出受影响材质及缺图路径。缺少图片的透明度遮罩无法恢复。GIS 静态兼容可从有效三角形重建无效法线，中文摘要按实际角点数量汇总。仍有贴图却没有 UV、非有限位置等问题继续拒绝。

成功须有真实 GDB、正确版本/后端/策略/坐标信息和关闭后重开核验。日志预览对大量输出作明确折叠与截断，原始诊断报告保留。兼容处理会显示“完成（有兼容处理）”，具体支持边界见 [compatibility.md](compatibility.md)。

本程序提供转换与报告，不含三维模型预览、批量队列、配准或烘焙。目标软件中的材质外观仍需独立验收，历史显示问题见 [acceptance.md](acceptance.md)。

完整构建命令见 [README](../README.md)。只发布 GUI 可用 `scripts/build.ps1 -WithGui`，完整交付需同时构建原生端并附带 FileGDB 运行库。历史截图见 [V0.1.2](validation-v0.1.2.md) 至 [V0.1.4](validation-v0.1.4.md)，其中的旧选项不属于本版。
