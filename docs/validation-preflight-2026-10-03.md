# 模型检查扩展验证 — 2026-10-03

本轮从 `master` 的 `6bcf786` 开始，版本保持 `0.6.0`，改动列入 Unreleased。新增 Python 与 WPF 模型检查入口，复用现有 CLI `inspect` 和共享读取器；补充核心报告的几何范围，修正已支持无光照材质映射的兼容标记。Scene Bundle、FileGDB 编码和新输出独占创建契约保持不变。

## 功能与边界

- Python 提供 `InspectionRequest`、`engine.inspect()`、结构化数量和范围结果，以及 `InspectionError`。仅检查 CLI 版本，不运行 writer；共用读取选项、路径快照和日志读取机制。报告要求来源、版本、策略、未定位的局部坐标、数量、范围、诊断及 fidelity 均符合请求。完成消息失败仍通过 `CallbackError.result` 保留已核验结果。
- GUI 增加“检查模型”和单独的检查报告入口。用户只需选择模型、读取策略及新 JSON 位置；无需 GDB、WKID 或原点。检查不改变先前转换成果入口。摘要明确标示“未写入 GDB”，给出数量、本地米制范围和警告。
- `geometry_bounds` 从保留三角形引用的角点位置计算，不重复应用已烘焙的源变换或原点，不计入未引用角点。所有角点仍参与验证；无效或空场景的范围为 `null`。Python/GUI 检查固定为本地右手 Z-up 米制、WKID 0、无原点平移；直接 CLI 显式提供原点时，范围包含该平移。
- 核心与原生报告共用兼容调整分类。修复前，GLB/glTF 的 `UNLIT_SHADING_MAPPED` 警告已存在，报告却称无兼容处理；修复后 `compatibility_adjustments=true`。核心报告的 `validation_passed` 仍为 true，而 `strict_validation_passed=false`，明确区分策略接受与无语义调整。原始模型颜色、贴图与角点边界保持不变。

模型检查覆盖读取器与共享场景验证；完整 PNG/JPEG 解码、原生存储约束及写入回读仍由后续转换验证。检查成功不等于 GDB 写入成功、地理位置正确或图形外观验收。MAX 检查仍需 Windows Max Batch 和相应许可，新增入口不扩大 MAX 已验证能力。

Windows Python 跳过 1 项 POSIX FIFO 和 3 项当前权限不允许的符号链接测试；目录联接替换检查实际通过。Ubuntu 符号链接与 FIFO 测试实际通过。两平台最终改动的实现及测试文件 SHA-256 一致。

模型检查集成测试覆盖 FBX、OBJ、GLB、glTF、WRL、DAE 的数量与精确范围、OBJ Y-up 厘米变换、两种 profile 的缺图回退/拒绝、目录型图片路径、损坏 PNG 签名、已有报告保留及消息回调失败保留结果。Python 显式指定不存在的 writer；GUI 把 CLI 单独复制到没有 writer/SDK 的目录，两者均实际检查成功。损坏 PNG 检查用例只验证签名拒绝；原生集成另保留完整图片解码损坏用例。

新增契约测试拒绝错误阶段、版本、来源、定位、非整数/矛盾数量、非有限或逆序范围、错误诊断及畸形 MAX 溯源；检查工作目录变化、贴图列表变更、报告冲突、链接替换、双流日志限额和已验证结果保留。核心范围测试覆盖多网格、负坐标、原点平移、无效未引用角点及空场景。完整 CTest 继续覆盖输出并发/链接、材质/UV/法线角点、放置来源和流式 Scene JSON。

## 已知限制与证据

Windows GUI 在深层工作区输出路径运行时，315 项中 4 项原有 OBJ/glTF/WRL/DAE 转换因贴图暂存路径过长而失败；使用新的短路径目录后 315/315 通过。此轮保留深路径失败记录，未声称修复既有 Windows 长路径限制。

未执行目标 GIS 三维外观、用户生产模型、GUI 屏幕布局或真实 Max Batch 环境验收；GUI 结果为 WPF 编译、服务契约和真实进程调用验证。未将协议替身测试描述为 MAX 实机验证。
