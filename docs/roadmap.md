# 路线图与版本规则

## V0.1.0 首版

完成可重复构建的 C++ 工程、严格 Scene 契约、writer 优先测试样本、静态 FBX 读取、可选 Pro 真实 GDB 写入与读回核对。原生 C++ FileGDB 后端保持不可用，避免伪造保真结果。

以上是已交付首版的历史范围；V0.1.0 样例和报告保持原样，旧 ZIP 已按 V0.1.2 交付要求移除。

## V0.1.1 小迭代

1. 增加独立 MSVC / FileGDB API 1.5.5 原生后端，完成实际写库、重开读回与跨后端核验。
2. 修复首版显示调查中发现的 UV 上下方向问题：所有有 UV 的 patch 写入 `U=sourceU, V=1-sourceV`，无纹理材质采用相同 UV 语义，中间包和图片行序保持不变。
3. 准备 ArcGIS Pro 本地场景、多视角布局与导出脚本，验收五组诊断模型及独立副本。
4. 分别记录源码实现、数值回归、成果独立性和图形显示结果，校验源码、程序和发行包版本一致。

以上是 V0.1.1 的迭代范围；该版实际状态见 [V0.1.1 验证记录](validation-v0.1.1.md)。

## V0.1.2 图形界面

提供 `geomodelbridgeGUI.exe`，将单模型转换、坐标参数、后端选择、附加贴图目录、环境检查、日志与报告放入 Windows 中文界面。界面继续调用同一 CLI 和后端，不另建转换算法。

本版改为工程目录交付，移除旧 ZIP 与校验文件，不生成新 ZIP。保留历史样例和验证记录；完整色彩、Alpha 和六面/接缝图形验收仍是独立待办。

## V0.1.5 原生独立部署

移除 Pro 转换后端、构建入口、授权探测及发布依赖，仅保留原生 FileGDB。CLI 明确拒绝旧后端，GUI 固定原生转换。历史证据保留来源，完整显示验收和从未安装 Pro 的客户机验收独立记录。所有提交直接进入 master。

## 后续阶段

V0.1.3 已增加显式 GIS 静态兼容策略，修复中性默认材质误报，并优化中文诊断摘要、报告查看和失败后换新名称重试。动画保存姿态、光照省略和零面积面删除均单独记录；不是完整材质烘焙。

- 用户真实建筑 FBX、目标 Pro/GeoScene 版本及其他 FileGDB API 版本的回归；合成样例通过不能推广到所有业务模型。
- 逐步扩展简单 PBR baseColor、OBJ/GLB Reader；新增格式仍走 Scene。
- 显式选择的烘焙/近似模式：必须报告源通道、转换策略和损失。
- 坐标配准/重投影独立模块；不把 WKID 赋值包装成配准。
- 增加每阶段计时、内存峰值、批量任务和性能优化，保持单库单写入。

V0.1.4 完成中间包流式写出、重复纹理散列复用和 GUI 日志有界预览；未新增批量转换、强制中止或重投影。

版本号格式 `V主版本.次版本.补丁`。项目首次交付为 V0.1.0，当前小迭代为 V0.1.5。更新版本需同步 VERSION、各 CMake project、include/gmb/scene.hpp、GUI csproj/report、当前版文档、测试断言和二进制。`scripts/check_version.py` 核对主要源码声明；历史证据和样例中的版本号不应批量替换。
